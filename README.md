# hq-sandbox
Repositorio **de prueba** de AI Headquarters. Sin datos reales, sin secretos, sin producción.
Los agentes de HQ trabajan aquí en ramas `hq/*` y abren PRs en borrador; **nunca** se hace merge automático a `main`.
Solicitud de ejemplo: [`docs/FEATURE_REQUEST_R1.md`](docs/FEATURE_REQUEST_R1.md).
